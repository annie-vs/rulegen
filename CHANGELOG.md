# Changelog

## v0.1.0 (2026-06-04)

Initial public release.

**Features**
- Parse Excel rule tables and auto-detect parameters and values
- Generate minimal-coverage test cases using the Pairwise algorithm
- Output `cases.xlsx` (test cases) + `coverage.html` (pair coverage matrix)
- `example` command to generate sample rule files in three domains (insurance, coupon, approval)
- Single-file Windows EXE — no Python installation required
